      What You Get

      Time Fit

      Ideas are scoped directly to the remaining hours you specify. The estimated hours are heuristic planning estimates, not guaranteed delivery milestones.

      Visible Scoring

      Every ranking computes a weighted rubric across time fit, feasibility, team fit, demo style, and theme. Each criterion includes its score and one-sentence reason.

      Duplicate Warnings

      Titles are checked against public GitHub repository records via title similarity. A potential match is an advisory warning to review prior art, not proof of copying.

      How Scores Work

      Scores are heuristic estimates produced by an LLM evaluated against a fixed scoring rubric, with mathematical weighting and ranking computed deterministically by the Python backend. They are designed for ideation prioritization and are not guaranteed facts. Always evaluate team velocity and library setup independently before building.

      Criterion Weight Evaluation Focus
      time_fit 25% (0.25) How realistically the minimum viable version (MVP) can be built within the hours entered.
      feasibility 25% (0.25) Realistic technical execution given the team skill level and preferred technology stack.
      team_fit 20% (0.20) How cleanly scope and parallel tasks divide across the specified number of developers.
      demo_fit 15% (0.15) Alignment with the intended presentation format (live app, slides heavy, or data story).
      theme_fit 15% (0.15) Direct connection to the hackathon track or theme (automatically scored 3 if no theme is given).
